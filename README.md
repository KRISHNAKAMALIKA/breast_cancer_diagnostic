**Project Name:** Breast Cancer Diagnostic
**Project Scope:** Data cleaning, EDA, visualization and ML models to classify tumors as malignant or benign.

## Dataset
Breast Cancer Wisconsin (Diagnostic), 569 samples and 30 features (Kaggle).

## Tools Used
Python, pandas, numpy, matplotlib, seaborn, scikit-learn, Google Colab

## Steps
1. Data cleaning
2. Exploratory data analysis and visualization
3. Training 5 models: Logistic Regression, KNN, SVM, Random Forest, Gradient Boosting
4. Evaluation using accuracy, precision, recall, F1 and ROC-AUC
5. Hyperparameter tuning of the SVM

## Results
Best models reached about 96-97% test accuracy. See `model_results.csv` and the `images/` folder.
